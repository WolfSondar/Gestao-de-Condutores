📄 Editor de PDF

Ferramentas

Nenhum PDF carregado.

Como usar

1. Importe um PDF.
2. Clique em um texto reconhecido para selecioná-lo.
3. Use Editar texto ou dê duplo clique.
4. Para colocar texto novo, use Adicionar texto e clique na página.
5. Baixe o PDF quando terminar.

Observação: esta versão edita textos detectados como uma camada sobre o PDF. Em PDFs escaneados, o conteúdo pode não ser reconhecido automaticamente.
